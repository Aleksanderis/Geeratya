  Ctrl-c     Cancel or close                                                                                            
  Up         Previous source in the picker                                                                              
  Ctrl-p     Previous source in the picker                                                                              
  Down       Next source in the picker                                                                                  
  Ctrl-n     Next source in the picker                                                                                  
  Ctrl-s     Save the comment                                                                                           
  Alt-Enter  Save the comment                                                                                           
  Left       Move the cursor left                                                                                       
  Right      Move the cursor right                                                                                      
  Home       Move the cursor to the start of the row                                                                    
  End        Move the cursor to the end of the row                                                                      
  Delete     Delete the character under the cursor                                                                      
                                                                                                                        
Palette commands                                                                                                        
  :jql <query>                                                                                                          
      Open a JQL query in a new tab                                                                                     
  :filter [name]                                                                                                        
      Open a saved filter in a new tab                                                                                  
  :board [name]                                                                                                         
      Open a board as columns in a new tab                                                                              
  :backlog [name]                                                                                                       
      Open a board's backlog in a new tab                                                                               
  :tab new|close|next|prev|<n>                                                                                          
      Open the source picker, close or switch tabs                                                                      
  :profile add|list|switch <name>|remove <name>|check                                                                   
      Manage Jira profiles                                                                                              
  :help                                                                                                                 
      Show or hide help                                                                                                 
  :quit                                                                                                                 
      Quit
