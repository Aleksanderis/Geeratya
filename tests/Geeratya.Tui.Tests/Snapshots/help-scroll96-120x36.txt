  Home       Move the cursor to the start of the row                                                                    
  End        Move the cursor to the end of the row                                                                      
  Delete     Delete the character under the cursor                                                                      
  Ctrl-o     Open the issue page in the browser from the form                                                           
                                                                                                                        
Palette commands                                                                                                        
  :jql [query]                                                                                                          
      Open a JQL query in a new tab (no query: pick from recent ones)                                                   
  :filter [name]                                                                                                        
      Open a saved filter in a new tab                                                                                  
  :board [name]                                                                                                         
      Open a board as columns in a new tab                                                                              
  :backlog [name]                                                                                                       
      Open a board's backlog in a new tab                                                                               
  :history clear                                                                                                        
      Forget the recent JQL queries and issues of this profile                                                          
  :tab new|close|next|prev|<n>                                                                                          
      Open the source picker, close or switch tabs                                                                      
  :status [next|prev]                                                                                                   
      Change the status of the selected or shown issue; next or prev moves the card a column                            
  :labels                                                                                                               
      Edit the labels of the selected or shown issue (field form)                                                       
  :profile add|list|switch <name>|remove <name>|check                                                                   
      Manage Jira profiles                                                                                              
  :keys reload                                                                                                          
      Read keymap.json again and apply it                                                                               
  :help                                                                                                                 
      Show or hide help                                                                                                 
  :quit                                                                                                                 
      Quit
