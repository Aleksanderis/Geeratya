Global  All actions  Commands                                                                                           
  :jql [query]                                                                                                          
      Open a JQL query in a new tab (no query: pick from recent ones)                                                   
  :filter [name]                                                                                                        
      Open a saved filter in a new tab                                                                                  
  :board [name]                                                                                                         
      Open a board as columns in a new tab                                                                              
  :backlog [name]                                                                                                       
      Open a board's backlog in a new tab                                                                               
  :history clear                                                                                                        
      Forget the recent JQL queries and issues of this profile                                                          
  :tab new|close|next|prev|<n>                                                                                          
      Open the source picker, close or switch tabs                                                                      
  :edit                                                                                                                 
      Edit the fields of the selected or shown issue (field form)                                                       
  :status [next|prev]                                                                                                   
      Change the status of the selected or shown issue; next or prev moves the card a column                            
  :labels                                                                                                               
      Edit the labels of the selected or shown issue (field form)                                                       
  :create [subtask]                                                                                                     
      Create an issue, or a sub-task of the selected issue (field form)                                                 
  :priority                                                                                                             
      Change the priority of the selected or shown issue (field form)                                                   
  :assign                                                                                                               
      Assign the selected or shown issue: search people, or unassign                                                    
  :assign-me                                                                                                            
      Assign the selected or shown issue to me                                                                          
  :profile add|list|switch <name>|remove <name>|check                                                                   
      Manage Jira profiles                                                                                              
  :set [hints.statusBar|hints.whichKey|commandlevel|theme|jump.target] [value]                                          
      List the settings, show one, or change one (saved)                                                                
  :theme [name]
