  Space i m  Assign the issue to me                                                                                     
  Space g    Jump to an issue by key                                                                                    
  Space n    Show the message history                                                                                   
  Space x    Dismiss the status message                                                                                 
  Space *    Switch the command level for the session                                                                   
  (7 advanced commands hidden; Space * shows them)                                                                      
                                                                                                                        
Help mode                                                                                                               
  j          Move down                                                                                                  
  Down       Move down                                                                                                  
  k          Move up                                                                                                    
  Up         Move up                                                                                                    
  ?          Show or hide help                                                                                          
  Space *    Switch the command level for the session                                                                   
  Esc        Close help                                                                                                 
  q          Close help                                                                                                 
  Ctrl-c     Quit                                                                                                       
                                                                                                                        
Command mode                                                                                                            
  Enter      Run the typed command                                                                                      
  Backspace  Delete the last character                                                                                  
  Up         Previous row in the picker                                                                                 
  Ctrl-p     Previous row in the picker                                                                                 
  Down       Next row in the picker                                                                                     
  Ctrl-n     Next row in the picker                                                                                     
  Esc        Cancel or close                                                                                            
  Ctrl-c     Quit                                                                                                       
                                                                                                                        
Confirm mode                                                                                                            
  y          Confirm                                                                                                    
  n          Decline                                                                                                    
  Esc        Decline
